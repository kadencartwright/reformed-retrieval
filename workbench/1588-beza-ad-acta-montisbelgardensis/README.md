# Theodore Beza, *Ad acta colloquii Montisbelgardensis responsio* (1588)

This directory contains an AI-assisted, unreviewed working Latin transcription and close English translation of both parts of Theodore Beza’s response to the published acts of the Montbéliard Colloquy.

## Controlling witnesses

- **Part I:** *Ad acta colloquii Montisbelgardensis Tubingae edita, Theodori Bezae responsionis, pars prior*, second edition (Geneva: Jean Le Preux, 1588), Bibliothèque de Genève Ba 1438** (1), e-rara DOI [10.3931/e-rara-6589](https://doi.org/10.3931/e-rara-6589), Public Domain Mark. Controlling PDF: `/tmp/beza-audit/ad_acta_part1_1588.pdf`.
- **Part II:** *Ad acta colloquii Montisbelgardensis Tubingae edita, Theodori Bezae responsionis, pars altera*, first edition (Geneva: Jean Le Preux, 1588), Bibliothèque de Genève Ba 1438** (2), e-rara DOI [10.3931/e-rara-6590](https://doi.org/10.3931/e-rara-6590), Public Domain Mark. Controlling PDF: `/tmp/beza-audit/ad_acta_montisbelgardensis_1588_both.pdf` (despite that local legacy filename, this 264-page object is Part II alone).

No modern English translation has been consulted or used as a wording source. The available 1587 first-edition OCR for Part I and the Utrecht OCR for Part II are used only as transcription aids; the 1588 e-rara images govern.

## Editorial conventions

- Each source boundary is marked with part, PDF page, logical source scan, and printed pagination (or a precise unpaginated/blank label).
- Running heads, page numbers, signatures, catchwords, ornaments, and non-textual press furniture are omitted. Substantive headings, marginal annotations, cited theses, documentary extracts, signatures, `FINIS`, and errata are retained.
- Latin spelling, capitalization, and punctuation follow the controlling images as closely as practicable; line-end hyphenation is silently joined except where a page marker intervenes. Illegible or supplied readings are documented rather than invented.
- The English files are close, complete working translations rather than summaries. They are AI-assisted and unreviewed and must be checked against the facsimiles before quotation or publication.
