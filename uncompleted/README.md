# Uncompleted translations

This directory contains source preparation and partial translations for the
non-Calvin corpus identified in
[`research/untranslated-latin-treatises.md`](../research/untranslated-latin-treatises.md).
Work-by-work progress and source blockers are recorded in
[`TRANSLATION_STATUS.md`](TRANSLATION_STATUS.md).

Folder placement records completeness only; it does not imply review or
publication status. A work moves to [`completed/`](../completed/) after all of
the following are present:

1. an identified public-domain Latin witness and stable source link;
2. a complete normalized Latin transcription with visible source-page markers;
3. a complete English translation with matching markers;
4. work-level metadata describing extent, omissions, uncertain readings, and
   AI assistance;
5. a full comparison of both files against the facsimile; and
6. repository validation and manifest updates.

Files remain here until all completion criteria above are met. The mere
presence of a file must not be cited as evidence of either a complete or a
reviewed English edition.
