# Theodore Beza, *De pace Christianarum ecclesiarum constituenda consilium*

> **Working edition:** This directory contains a complete AI-assisted
> transcription and translation of the delimited work. It is not yet an
> independently reviewed or publication-ready edition.

## Work identity

- **Author:** Theodore Beza (first published anonymously)
- **Title:** *De pace Christianarum ecclesiarum constituenda, consilium pii et
  moderati cuiusdam viri*
- **First edition:** Geneva, Jean Crespin, 1566
- **Subject:** Counsel for establishing peace among the Protestant churches

## Base witness and boundaries

The controlling text is Beza's author-revised 1582 *Tractationes theologicae*,
volume II, printed pp. 110–121:

- [volume record](https://www.e-rara.ch/zuz/content/titleinfo/7595651)
- [isolated chapter PDF](https://www.e-rara.ch/download/pdf/5163822.pdf)
- [IIIF manifest](https://www.e-rara.ch/i3f/v20/7595651/manifest)

The work occupies physical scans 115–126. On printed p. 121 it ends above the
beginning of the distinct *Defensio sacramentalis coniunctionis*; material from
that following work is excluded. The 1582 images are marked Public Domain and
control the text. OCR from an [earlier collected
witness](https://archive.org/details/bub_gb_Hlwzf7UCcdEC) is used only as a
transcription aid. The [1566 standalone
edition](https://www.e-rara.ch/gep_g/content/titleinfo/1751752) supplies a
second public-domain image witness.

## Current files

The `parts/` directory now contains a complete working transcription and
translation through `FINIS`:

- `parts/complete-latin.txt`
- `parts/complete-english.md`

Both files carry the complete sequence of printed-page markers 110–121 and
stop before the distinct *Defensio sacramentalis coniunctionis* that begins on
printed p. 121. The 1582 images and OCR objects 0114–0125 were checked page by
page. One difficult source reading on p. 119, *qui spiritualia metendo*, is
preserved and explicitly footnoted rather than silently emended. The files
remain working editions pending independent Latin and historical review.
