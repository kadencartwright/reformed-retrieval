# Completed translations

This directory contains all **82 completed source-and-translation units** in
the repository. “Completed” means that the full source boundary documented by
the work's README has both a transcription and an English translation. It does
not mean independently reviewed or publication-ready.

The [repository README](../README.md#completed-corpus) catalogs every completed
text with its author, date, title, and extent. Each work directory supplies
detailed witness, boundary, editorial, and review information.

Short documents use `latin.txt` or `french.txt` alongside `english.md`. Longer
works use paired `parts/*-latin.txt` and `parts/*-english.md` files.
