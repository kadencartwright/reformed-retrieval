# Translation workbench

This directory contains source preparation and working translations—some
complete as delimited drafts, many still incomplete—for the non-Calvin corpus identified in
[`research/untranslated-latin-treatises.md`](../research/untranslated-latin-treatises.md).
Work-by-work progress and source blockers are recorded in
[`TRANSLATION_STATUS.md`](TRANSLATION_STATUS.md).

Nothing here is a published or reviewed edition. A work moves to `texts/` only
after all of the following are present:

1. an identified public-domain Latin witness and stable source link;
2. a complete normalized Latin transcription with visible source-page markers;
3. a complete English translation with matching markers;
4. work-level metadata describing extent, omissions, uncertain readings, and
   AI assistance;
5. a full comparison of both files against the facsimile; and
6. repository validation and manifest updates.

Files remain in the workbench until all publication criteria above are met.
The status ledger distinguishes a complete working draft from an incomplete
part or a source audit; the mere presence of a file must not be cited as
evidence of a reviewed English edition.

All John Calvin works are outside the scope of this workbench. The existing
Calvin and Socinus editions under `texts/` are unaffected.
